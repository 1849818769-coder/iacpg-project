# 数组越界检查清单

仅在所有项目都成立时确认 `interrupt_aware_array_oob`：

1. 存在使用从共享状态派生的索引、游标或界限的数组访问。
2. 一个上下文验证或计算索引/范围。
3. 另一个上下文可以中断并在数组访问前改变相关状态。
4. 结果访问可以超过合法界限或命中无效元素。
5. 汇点是具体的数组读取或写入。

## 强阳性模式
- 验证 `idx < N`，ISR递增 `idx`，稍后写入 `arr[idx]`
- 计算 `top = N - 1`，ISR改变标志使重新计算会产生 `N`，但使用过期值
- 一个ISR更新索引，而另一个ISR或main使用过期的已检查索引进行写入

## 拒绝作为数组越界当
- 索引在汇点被安全地掩码/限制
- 中断仅改变数组内容，不改变索引/界限逻辑
- 在每种可行交错下访问都保持在界限内

## 报告重点
- 识别已检查/计算的索引源
- 识别中断更新
- 显示最终的越界访问
