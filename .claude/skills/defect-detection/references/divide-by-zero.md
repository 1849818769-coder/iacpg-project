# 除零错误检查清单

仅在所有项目都成立时确认 `interrupt_aware_div_zero`：

1. 分母、除数或步长值被共享或从共享状态传递派生。
2. 一个上下文检查或计算它为安全/非零。
3. 另一个上下文可以中断并在除法汇点前改变它。
4. 存在真实的除法或等效的分母使用。
5. 交错执行可以使分母为零或无效。

## 强阳性模式
- `if (d != 0) { use 1 / d; }` 配合ISR写入 `d = 0`
- 从共享计数器计算 `step`，ISR改变计数器，稍后除以 `step`
- 验证和除法被调用或分支分隔，同时中断保持启用

## 拒绝作为除零错误当
- 在可行交错下除数不能变为零
- 所有更新在使用前将值限制远离零
- 没有实际的除法汇点

## 报告重点
- 显示检查行、中断写入行和除法行
- 命名变为零的变量
- 解释为什么汇点在中断后可达
